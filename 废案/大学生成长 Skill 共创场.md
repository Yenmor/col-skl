# 大学生成长 Skill 共创场



### 信息来源

	1. onebot 适配器，从零散的 QQ 群消息里收集消息，总结文档信息
	1. 文档上传，热心群众直接上传文档
	1. 使用搜索 api 直接从互联网搜索

> 用户或许也只有零散的信息，QQ 消息也只有零散消息，搜索 api 得到的结果也基本是零散消息，需要提供一个 skill 将信息组织为标准文档



### 信息二次分类

	1. 首先对信息做最基本的分类，按照院校，年份，领域做最基础约束工程
	1. 以某种数据存储方式组织这些数据
	1. 或许要把组织后的数据用于 RAG



### 产物

	1. 前端直接聊天窗口，比如问 ”山西大学保研政策“ 给出充足的信息并标出来源
	1. 信息检索服务，区别于聊天接口，更加确定，更加接近事实源
	1. 暴露一些接口和输出一份 skill 用户可以自行将 skill 接入自己的工具然后使用服务，接口返回的可能是一种类似 RAG 搜索结果的东西。
	1. 前文信息收集提到的skill，用户可以输入零散的信息，然后 skill 自动总结为标准文档



### 明确的未定内容

1. 此为黑客松比赛产品，需要两三个人48小时内尽可能开发完毕，所以需要一种协作模式
2. 前端选择 flutter 制作的手机 app 还是单纯的网页，这个选择会不会对开发效率造成影响
3. 目前的想法是前后端分离，但是需要知道前后端可能要对接的接口
