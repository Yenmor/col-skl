# 工作原文（work.md）

## 怎么找导师

1. 查学校教师主页，挑 1-3 个研究方向与你重合的
2. 读他近 1-2 年的 2-3 篇代表作
3. 发邮件：开头讲你读过他某篇论文的真实感受（一两句），然后附简历 + 成绩单
4. 邮件标题明确：「本科 + 学校 + 申请方向 + 大学几年级」
5. 不要群发；要针对每位老师改 200 字的初稿

## 怎么读论文

- 第一轮：标题 + 摘要 + 图表 + 结论，30 分钟能看完
- 第二轮：方法 + 实验，关键段落精读
- 第三轮：自己做一遍作者的实验逻辑（哪怕是纸面推算）

## 时间分配

- 大二下：每周 4-6 小时读论文
- 大三上：进入课题组，每周给老师汇报一次（哪怕只是 demo）
- 大三下：争取一个小成果（哪怕是 workshop abstract / 中文核心）
