# 最说人话项目介绍

## 我们做的是什么：

	- 一个社区
	- 一个助手
	- 一个 skill hub
	- 一个信息存储库



### 一个社区：

- 一个人们可以分享，交流经验的地方，同时也是 “一个助手” 的宝贵数据源

### 一个 skill hub

- 为了社区经验不被浪费，对于那些发言极多，干货极多，风格迥异的人们，我们提供了 metaskill 来讲这些校园领域大神蒸馏成 人.skill。大神轻点平台按钮，他的经验便可以共享出来，为其他人所用。别人轻轻一点，也可以轻松复用这些经验。

### 一个信息存储库（RAG）

- 不是所有人都是活跃用户，也不是所有人都能系统系的发表文章，对于那些散落在边角，无法被整理的信息，我们将其本身和其有限的上下文存储进平台内置的 RAG 中，在需要信息的时候可以被召回作为信源-

### 一个助手

- 拥有 skill 和 RAG 库后，我们平台提供一个小助手来活络的使用这些优质资源，用户向助手提问后，助手会智能加载合适领域的 人.skill，来对用户的问题进行解答

## 一些疑问

### 为什么使用 人.skill ?

人对于一个事物的经验是多样性的，而不是单一的某个领域大神，人擅长的地方是由他擅长的其他地方所决定的，他们之间有机结合才产出了具有人情味的回答。很多人在 ai 时代，也偏向于和人聊天而不是和 ai 聊天，人的复杂经验所内化出的表现形式和偏好是单纯的针对某个技能的 skill 无法赋予的

### 为什么自带一个助手，直接提供 skill 下载不好吗？

现代 ai 工具实际上已经十分强大，如果一个人懂得装 skill ，那么他大概率是一个先进且极其富含能量和有主见的人，他或许并不需要一个来源于别人的经验的 skill 来指导自己。即便这些人欣赏我们的平台并使用，这也总是人群中的一小部分，而不是需要帮助的大多数。我们前端提供对话接口，将使用技能的**认知成本**降到最低，成为真正能给绝大多数大学生指导的产品
